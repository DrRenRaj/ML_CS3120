# Setup guide

## Option 1: Google Colab (recommended)

Click any **Open in Colab** badge in the book. Nothing to install.

## Option 2: Run locally

```bash
git clone https://github.com/DrRenRaj/ML_CS3120.git
cd ML_CS3120/code
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
```
